Kkang 서랍 보관소 관리 홈페이지 보기

관리자 확인

글을 쓰고 고치려면 GitHub 접근 토큰이 필요합니다. 처음 한 번만 발급받아 아래에 붙여 넣으세요.

  1. GitHub 토큰 만들기 화면을 엽니다.
  2. Token name에 "Kkang 홈페이지"처럼 알아볼 이름을 적습니다.
  3. Expiration에서 사용할 기간을 고릅니다.
  4. Repository access에서 "Only select repositories"를 고르고 KKang을 선택합니다.
  5. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  6. 맨 아래 Generate token을 누르고, 나온 토큰을 복사해 아래 칸에 붙여 넣습니다.

토큰은 지금 쓰는 이 브라우저에만 저장되고 GitHub 외에는 어디에도 보내지 않습니다. 공용 컴퓨터에서는 사용 후 "토큰 지우기"를 눌러 주세요.

보관한 글

    저장한 글은 1~2분 뒤 홈페이지에 나타납니다.
